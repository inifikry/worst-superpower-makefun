# Worst Superpower

Entry for the make.fun bounty **Worst Superpower**
(`u-suroto-worst-superpower-461dcdbe`).

## The entry

> I can fly, but only two inches off the ground, only downhill, and only as fast as I can walk.

Flight is the classic superpower. Three small-print clauses ruin it:
two inches of altitude, downhill only, at walking speed. A hero who
hovers just above the pavement, gliding downhill no faster than a
stroll, achieves exactly nothing that walking does not.

## How it works

`main.py` writes that single line to `/output/entry.txt` (1-140
characters, one line, UTF-8). It validates the gate before writing:
length, non-whitespace, and no newline.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
